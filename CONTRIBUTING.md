# Contributing

Thank you for considering a contribution.

## Rule

> Do not add complexity unless it solves a demonstrated problem.

## Process

1. Keep changes small and measurable.
2. Prefer fixing docs/tests before adding features.
3. Run `dotnet test`.
4. Avoid new dependencies unless unavoidable.

## Style

- Minimal API, plain SQL, Markdown-first responses
- No ORM, no microservices, no SPA
